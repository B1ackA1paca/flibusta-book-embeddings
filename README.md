# Flibusta Book Semantic Embeddings Training Pipeline

Репозиторий содержит модульный пайплайн для семантического анализа и получения сквозных векторных представлений (эмбеддингов) книг большого объема из датасета Флибусты. 

В основе решения лежит идея представления книги как последовательности смысловых чанков с последующей агрегацией их векторов через трансформер-суммаризатор.

## Архитектура и Стек
* **Основная модель:** `Alibaba-NLP/gte-multilingual-base` (замороженные веса + файнтюнинг через LoRA/PEFT).
* **Агрегатор (Summarizer):** Кастомный Transformer Encoder для сжатия последовательности векторов чанков в один итоговый эмбеддинг книги.
* **Лосс-функция:** InfoNCE Loss (контрастивное обучение) для сближения векторов книг с их семантическими паспортами.
* **Оценка качества:** Валидация по метрике Recall@5.
* **Стек:** Python, PyTorch (с использованием смешанной точности AMP/Scaler), Hugging Face Transformers, PEFT, Scikit-Learn, Pandas, NumPy.

## Структура проекта
* `src/data_prep.py` — предобработка fb2-файлов, очистка текста, парсинг индекса `.inpx`.
* `src/models.py` — архитектура `BookSummarizer` и `FullBookEncoder`.
* `src/dataset.py` — пайплайн ленивой загрузки предобработанных векторов.
* `precompute.py` — скрипт для предварительного расчета эмбеддингов паспортов книг.
* `train.py` — цикл контрастивного обучения модели с валидацией.
